# CodeClip

CodeClip is our CS 571 web project. The goal is to help users convert code from screenshots and programming videos into editable files.

This is our initial prototype based on the design we created in Figma.

## Running Locally

```bash
pnpm install
pnpm dev
```

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
